# 代码审查记录（实施基线）

- 配置：验证输入、种子、7:2:1、输出根、模型和优化参数；每次解析快照。
- 隔离：拆分发生于任何预处理前；预处理只拟合训练集；优化接口不接收测试集。
- 指标：统一二元混淆矩阵和零分母不可计算状态。
- 池一致性：候选保存 pool_uid；融合和最终重训断言 uid、长度及特征/训练索引哈希；清单逐槽保存 f/i。
- 进化：初始化一个池，每代一个 trial 池；父解缓存其绑定清单。
- 复杂度/PROMETHEE：参数化系数、最小化方向、q/p、权重和净流均记录。
- 输出：运行目录唯一，含命令、状态、快照及报告。

遗留风险：标签的业务语义、标签派生/近重复、组或时间泄漏，以及 spMODE-II 原算法细节不可由本地文件自动证明；需要用户或可核实原始资料确认。
