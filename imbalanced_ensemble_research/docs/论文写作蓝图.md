# 中文硕士论文写作蓝图（2万–3万字）

1. **绪论（3500–4500字）**：可写研究背景、类别不平衡挑战、研究问题与贡献边界；待补可核实文献与实际研究动机证据。
2. **理论与相关工作（4000–5000字）**：可写分类不平衡、集成学习、多目标决策的概念框架；待补经过核验的文献比较，不能虚构引用。
3. **方法（5000–6000字）**：可立即依据方法草稿写 7:2:1 隔离、x=(f,i,m,w)、RBF-SVM 池、复杂度和 PROMETHEE；须明确 spMODE-II-inspired 的未核实差异。
4. **实验设计与结果（5000–7000字）**：可写数据审计方法、指标和可复现配置；必须等待真实运行后填入数据表、基线/集成指标、混淆矩阵、ROC/PR 图、帕累托图、跨种子统计与失效案例，不能预填数值或结论。
5. **结论与展望（2000–3000字）**：待真实结果后概括发现与局限；可先写未来需核验标签语义、组/时间切分和原算法细节。

建议总字数 20,000–30,000。参考 PDF 只能用于观察标题层级、图表和参考文献的版式，不复制其文字。开题计划中“2028年12月至2028年06月”为倒序，应改为“2028年06月至2028年12月”；实际时间安排仍请作者确认。

建议待真实结果生成的图表：数据集类别/质量表、拆分表、基线与最终集成测试指标表、每模型混淆矩阵、ROC/PR 曲线（可计算时）、验证帕累托散点、PROMETHEE 净流表和多种子聚合表。
